# 메모리 제품 기본 지도

기준일: 2026-11-05. 제품 세대별 성능 숫자는 빠르게 변하므로 본문은 정의 중심이다.

## 제품군 구분

| 구분 | 무엇인가 | 일반적인 업무 포인트 | 주의 |
| --- | --- | --- | --- |
| DRAM | 전원이 끊기면 저장 내용이 사라지는 동적 메모리 | 서버·PC·모바일의 주기억장치, 대역폭과 지연시간 | 공정·인터페이스·제품 규격을 분리 |
| HBM | DRAM 다이를 적층하고 넓은 연결로 높은 대역폭을 제공하는 제품군 | AI 가속기·HPC의 메모리 병목, 대역폭·용량·전력·적층 | HBM은 '비DRAM 별도 메모리'가 아님 |
| NAND Flash | 비휘발성 플래시 메모리 | SSD·스토리지의 용량·원가·내구성 | NAND와 SSD는 제품 계층이 다름 |
| SSD / eSSD | NAND 기반 저장장치(컨트롤러·펌웨어 포함), eSSD는 기업/서버용 | 처리량, IOPS, 지연시간, 내구성, 장애율 | NAND 칩 실적과 SSD 출하를 직접 혼동 금지 |
| DDR5 | DRAM 인터페이스/규격 세대 | 시스템 호환성, 속도, 용량, 플랫폼 검증 | HBM과 서로 같은 지표로 단순 비교 불가 |

HBM4는 JEDEC이 2025-04-16에 발표한 JESD270-4 표준으로 정의되어 있으며, 세부 칩 사양은 제조사·제품별로 확인해야 한다. 제품의 개념, 표준, 실제 출시 시점, 매출 기여 시점은 서로 다른 사실이다.

## 시장·제품 분석의 핵심 축

1. **수요:** AI 학습·추론 서버, 일반 서버, PC, 모바일, 저장장치 수요를 나눈다.
2. **공급:** 웨이퍼 투입, 생산능력, 수율, 패키징 제약, 고객 승인, 투자 계획을 구분한다.
3. **가격:** ASP는 판매금액/판매량의 개념이나 제품 믹스·단위가 다른 경우 직접 비교하면 안 된다.
4. **성장:** YoY와 QoQ는 비교 기준이 다르므로 기준연도·분기를 함께 표기한다.
5. **수익성:** 매출총이익률·영업이익률·순이익률을 혼동하지 않는다. 환율·제품 믹스·비용과 연계해 검토한다.
6. **전망:** 기업 발표와 시장 예측은 사실이 아니라 해당 시점의 전망이며 업데이트 대상이다.

## 흔한 오류

- HBM = GPU라고 설명: HBM은 GPU/AI 가속기 등에 연결되는 메모리.
- '최신' HBM 제품의 대역폭·용량을 모든 제품의 보편적 특성으로 표현.
- 용량(GB), 대역폭(GB/s), 데이터 전송률(Gbps), 지연시간(ns)을 동일한 속도 지표로 취급.
- NAND 생산량 증가를 SSD 완제품 매출 증가와 동일시.
- 한 시점의 경쟁사 실적만으로 시장점유율을 단정.
