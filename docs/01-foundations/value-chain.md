# 반도체 밸류체인과 이해관계자

## 밸류체인 연결

연구·지식재산(IP) → 설계(EDA, 팹리스 또는 IDM) → 웨이퍼 제조(파운드리 또는 IDM) → 조립·패키징·검사(자체/OSAT) → 완제품 제조사·고객.

소재·장비·소프트웨어 공급사는 여러 단계에 **가로질러 참여**한다. 실제 공급망은 다단계·다국가 구조다.

| 구분 | 역할 | 분석 쟁점 |
| --- | --- | --- |
| Fabless | 반도체 설계 중심, 제조 위탁 | IP, 설계비, 제조파트너 의존도 |
| Foundry | 고객 설계의 위탁 제조 | 공정 경쟁력, 생산능력, 수율 |
| IDM | 설계·제조·판매 통합 | 내부 투자·제품 포트폴리오 |
| OSAT | 외주 조립·패키징·테스트 | 첨단 패키징, 생산능력, 납기 |
| Equipment | 노광·증착·식각·검사 장비 공급 | 장비 리드타임, 설치·서비스 |
| Materials | 웨이퍼·가스·화학약품·포토레지스트 등 | 순도·공급 안정성·대체 가능성 |
| OEM/클라우드 | 반도체를 사용하는 고객 | 성능, 가격, 전력, 공급계약 |

SK하이닉스는 메모리 제품 중심 기업으로, 메모리 제조·패키징·출하와 관련된 다양한 공급사·고객과 연결된다. 특정 회사의 공급사 실명이나 계약 조건은 공식 공개 자료로 확인되기 전까지 단정하지 않는다.

## 시나리오 분석 절차

1. 변화 요인 선택: 수요 급증, 소재 부족, 수출 규제, 신공정 도입, 패키징 병목.
2. 직접 영향받는 노드 확인: 장비/재료/제조/패키징/고객.
3. 전파 경로: 공급량 → 납기 → 가격/투자 → 품질/고객 승인 등으로 나눔.
4. 각 노드에서 확인할 지표: 공급 비중, 대체 가능성, 리드타임, 품질인증, 재고일수.
5. 최소 2개 대안과 리스크, 추가 데이터 요청을 명시.

## 주의

- '파운드리가 설계를 한다' 또는 'OSAT가 제조 전 공정을 담당한다'는 식으로 역할 혼동 금지.
- 생산시설 소재지나 발표 시점과 실제 가동 시점을 분리.
- 공식 보고서의 전망 숫자는 자료 작성 시점 한정.
- 단일 업체의 주가를 기술·공급망 경쟁력의 직접 증거로 취급하지 않음.
