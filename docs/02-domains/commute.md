# 도메인: 사업장 통근버스 운영·문의

**페르소나 유형:** 통근 운영 매니저, 배차 최적화 분석가, 구성원 지원 담당자.

## 업무 목적
구성원이 정해진 시간에 안전하게 출퇴근하도록 노선·차량·정류장·시간표를 운영한다. 실제 특정 회사의 사내 교통노선 정보는 여기 제공하지 않는다.

## 최소 입력
- 정류장 위치와 유효한 승하차 수요(개인 주소 대신 집계 권장)
- 날짜/요일별 수요, 근무조/교대 시각, 입실 마감시각
- 버스별 좌석 수, 운행 가능 시간, 휴게·법적 제한 조건
- 정류장 간 예상 소요시간(시간대·교통상황 반영)
- 필수 경유지, 운행예산, 변경 불가 노선과 공지 기한

## 목표함수와 제약조건 구분
| 유형 | 예시 |
| --- | --- |
| 강제 제약 | 좌석수 이하, 필수 승객 수송, 교대조 시작 전 도착 |
| 선택 제약 | 최대 대기시간, 과도한 환승 최소화 |
| 최적화 목표 | 평균 통근시간, 총 차량 비용, 접근성 불균형 감소 |
| 경영/노무 검토 | 형평성, 일정 변경의 영향, 안전 |

버스 노선은 Google OR-Tools의 **차량경로문제(VRP)·용량제약·시간창**으로 개념화할 수 있지만, 실제 구현에서는 교통데이터와 운영 규정이 필요하다.

## 구성원 문의를 처리하는 법
1. 문의 분류: 시간, 노선, 분실물, 지연, 좌석, 접근성, 안전.
2. 현재 공지된 운영 정책과 실제 최신 배차표 확인.
3. 불확실한 경우 추정 도착시간임을 표시하고 재확인 경로 안내.
4. 개인정보가 들어간 문의는 공개 저장소·공유 채널에 남기지 않음.

## 데이터 예시
stop_id, date, shift_code, planned_departure, observed_arrival, seat_capacity, boarded_count, delay_minutes.

예시 필드이며 특정 사업장의 운영 스키마가 아니다.
