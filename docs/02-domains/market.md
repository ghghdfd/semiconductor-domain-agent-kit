# 도메인: 메모리 시장·경쟁사·실적 전략

**페르소나 유형:** 시장전략 분석가, 산업 연구원, 사업기획 담당자.

## 어떤 결정을 돕나
- 특정 분기 DRAM/HBM/NAND 사업의 성장·수익성 변화 원인을 분석한다.
- 경쟁사 전략과 가격·공급·패키징 제약을 비교한다.
- 제품 포트폴리오 및 시장 변화에 대한 실행 가능한 시사점을 낸다.

## 최소 데이터 사전
| 지표 | 정의/검증 |
| --- | --- |
| Revenue/매출 | 공시의 연결/별도 범위, 회계기간, 화폐 및 환율 |
| Operating profit/margin | 영업이익률 = 영업이익/매출 × 100. 비경상 항목 주의 |
| ASP | 평균판매가격. 제품군의 단위·믹스 변화 통제 필요 |
| Bit growth | 메모리 생산/출하 용량 기준 성장, 단순 개수 성장과 다름 |
| CAPEX | 설비투자. 발표 계획과 집행 금액 구별 |
| Market share | 매출기준 또는 공급량 기준인지 먼저 정의 |
| HBM product mix | HBM 포함 여부, 세대, 고객 승인·인도 타이밍 구별 |
| QoQ/YoY | 직전 분기 비교 / 전년 같은 분기 비교. 명목과 실질 구별 |

## 분석 순서
1. 주어진 질문을 의사결정으로 재작성. 예: '어느 제품이 성장에 기여했는가?'.
2. 공시 기간·통화·연결범위가 동일한 원본 1차자료 수집.
3. 지표를 표준화하고 원자료를 변환한 절차 기록.
4. 실적 변화를 **가격 / 판매량 / 믹스 / 비용 / 환율**로 나눠 '확인된 것'과 '추정'을 표시.
5. 경쟁사 비교 시 제품 구성과 사업부 정의 차이를 설명.
6. 2~3개 시나리오를 조건부로 제시하고 결론을 바꿀 반증 데이터를 제시.

## 보고서 출력 틀
- 핵심 결론 한 줄
- 비교기간과 데이터 범위
- 지표 표: 원자료, 계산식, 기준일
- 주요 관측과 잠정 원인
- 반대 설명·데이터 누락·의사결정 리스크
- 실행 제안(시한, 판단 조건, 담당자)

## 오답 방지
- 투자·주가 전망을 자동으로 확정적 사업 전략으로 바꾸지 않는다.
- 분기 실적의 성장률을 연간 성장률과 혼동하지 않는다.
- HBM과 일반 DRAM의 가격을 동일 단위로 직접 비교하지 않는다.
- 회사 가이던스와 외부 조사기관 추정치를 동일한 신뢰도로 취급하지 않는다.
