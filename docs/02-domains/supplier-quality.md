# 도메인: 반도체 소재·공급사 변경 검토

**페르소나 유형:** 소재 품질 엔지니어, 공급사 품질 관리자, 구매·제조 연계 담당자.

## 업무 목표

소재를 교체하거나 공급사를 추가할 때 **가격·납기 개선이 공정 안정성과 고객 품질을 훼손하지 않는지** 판단한다. 단순히 단가가 싸다는 이유만으로 승인하지 않는다.

## 핵심 개념
- **COA(Certificate of Analysis):** 공급 로트의 시험·분석 성적서. 인증서만으로 공정 적합성이 보장되지 않음.
- **Lot Traceability:** 원재료/공급사/입고/사용/완제품까지 추적하는 체계.
- **Spec vs Control Limit:** 제품 허용 규격과 실제 공정 안정성 판단 한계는 별개.
- **FMEA:** 고장 형태·원인·영향을 구조적으로 검토하는 리스크 평가 방법.
- **Change Control:** 소재·공정·공급사 변경의 승인과 문서화.
- **Qualification:** 실사용 조건에서 대체 소재를 평가하고 정해진 승인 절차를 밟는 과정.
- **CAPA:** 문제 발생 시 시정 및 재발 방지 활동.
- **SPC/Cpk:** 변동과 능력을 점검하는 통계적 개념. 필요한 가정·표본·규격 없이 단일 수치로 승인 판정하지 않음.

## 판단할 7개 축
1. 기술 적합성: 순도, 불순물, 입자, 물성, 공정 적합성.
2. 안정성: Lot 간 편차, 보관 조건, 유효기간, 장비와의 상호작용.
3. 품질: 불량률·결함 분포·재검 비율·수율 영향.
4. 평가: 시험 설계, 샘플 수, 측정 신뢰성, 기존 대비 대조군.
5. 공급망: 이원화, 공급 중단 대비, 리드타임, 생산 거점.
6. 경제성: 단가 + 검증비 + 전환비 + 폐기비 + 실패 리스크.
7. 준수: 고객 승인, 물질 안전 및 적용되는 규정, 기록 보존.

'미확인' 상태는 실데이터를 넣기 전의 예시이며 실제 의사결정 결과가 아니다.

## 결론 작성
- **승인 / 조건부 승인 / 보류 / 반려**를 권고할 수 있으나, 권한 있는 담당자의 공식 승인과 혼동하지 않는다.
- 데이터 부족·시험 필요·잔여 리스크를 정량/정성으로 분리한다.
- 실제 기밀 스펙, 장비 레시피, 공급계약은 공개 저장소나 외부 도구에 입력하지 않는다.
