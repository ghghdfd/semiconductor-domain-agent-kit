# 자연어 → 수리최적화 모델

## 최소 구성요소

1. **집합(Sets):** 작업자, 작업, 설비, 시간대, 장소 등 대상의 범위.
2. **파라미터(Parameters):** 비용, 시간, 수요, 용량, 자격 등 실제 입력값.
3. **결정변수(Variables):** 솔버가 선택할 값. 예: 0/1로 배정 여부를 표현.
4. **목적함수(Objective):** 비용 최소화·만족도 최대화 등 단일 명확한 목표.
5. **강제 제약(Hard constraints):** 절대 위반 불가한 수식/규칙.
6. **선호·패널티(Soft constraints):** 포기 가능하지만 비용이 발생하는 조건.
7. **수용 검증(Acceptance tests):** 값만으로 통과·실패 판단 가능한 검사.

## 가상 할당 문제

작업자 집합 W, 작업 집합 T, 배정 비용 c(w,t). 변수 x(w,t)는 작업자 w가 작업 t를 담당하면 1, 아니면 0.

목적: minimize sum(w in W, t in T) c(w,t) * x(w,t).

강제 제약:
- 각 작업 t에 대하여 sum(w in W) x(w,t) = 1.
- 각 작업자 w에 대하여 sum(t in T) x(w,t) <= 1.
- 특정 자격이 없는 (w,t) 조합은 x(w,t) = 0.
- x(w,t) ∈ {0,1}.

'비용'이 금액인지 점수인지, 결측값이 금지인지 미확인인지 명시해야 한다. 항목별 단위가 다르면 일관된 스케일이 필요하다.

## 어떤 조건을 수식으로 옮겨야 하나

| 자연어 | 모델링 질문 |
| --- | --- |
| 인원당 하루 한 번만 배정 | 대상·날짜·한도 단위를 특정했는가? |
| 전 작업 완수 | 반드시 모든 작업을 배정하는가, 누락 패널티가 있는가? |
| 매일 균등하게 | 정확한 균등인가, 편차를 최소화하는 선호인가? |
| 비용과 시간을 모두 줄여라 | 우선순위가 있는가, 가중치·Pareto 비교인가? |
| 안전을 보장하라 | 어떤 측정 가능한 위험/법적 제약인지? |

## 모델 품질 체크

- 숫자가 누락된 곳을 임의 0으로 채우지 않는다.
- 시간(분), 금액(원), 수량(개), 비율(0~1/%) 혼용 금지.
- 설비·직원·자재의 ID와 시간대 집계를 정확하게 연결.
- 논리적 비선형 조건을 LP에 억지로 넣지 않는다. CP-SAT나 선형화 필요.
- Big-M 사용 시 상한을 근거 없이 매우 크게 잡지 않는다. 수치 안정성·완화 경계 문제 검토.
- 목표가 없어도 실행 가능한 해를 찾는 것이 충분할 수 있다.
- 수용 기준은 solver의 목적함수와 별도로 다시 계산할 수 있어야 한다.
