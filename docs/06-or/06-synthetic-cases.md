# 합성 연습 사례 — 실제 평가문항과 무관

## 사례 A: 작은 작업 배정
- 3명의 작업자와 3개의 업무가 있다.
- 비용행렬이 주어질 때 모든 작업에 정확히 한 명을 배정하되 1인당 1개 이하를 담당한다.
- 특정 배정은 자격 미달이라 금지된다.
- 목표는 모든 조건을 만족하는 최소 비용 배정이다.
- [합성 입력 데이터](../../examples/or/assignment.json)와 [표준라이브러리 풀이](../../scripts/solve_assignment.py)를 사용.
- 이 작은 예제의 완전탐색 결과는 최적성을 입증할 수 있지만, 실제 업무의 큰 데이터에 같은 방식 적용 금지.

## 사례 B: 교대 근무표
- 가용 인원, 기간, 교대조 수, 최대 근무일, 연속 근무 금지, 선호도를 분리.
- '선호'는 강제가 아닌 목적함수로, 법적 제한은 강제 제약으로 구성.
- [Google 공식 Employee Scheduling](https://developers.google.com/optimization/scheduling/employee_scheduling) 참조.
- 실제 제도와 법령을 임의로 설정하지 않는다.

## 사례 C: 복수 차량 경로
- 차량 수, 적재 제한, 출발지, 거리/시간 행렬, 방문 시간창을 정의.
- 총 거리 최소와 최장 차량 운행시간 최소는 **서로 다른 목적**이다.
- [Google 공식 VRP](https://developers.google.com/optimization/routing/vrp) 참조.

## 사례 D: 공급사 선택
- 품질/납기 승인 조건을 강제 제약으로, 비용을 최소화 대상 또는 비교 지표로.
- 공급사가 여러 명이고 분할 발주가 가능한지 먼저 확인.
- 실제 불량률이나 계약 조건이 없다면 최종 승인 판정을 하지 않는다.

## 사례 E: 대화형 요구사항 추출
- 가상 관계자 A: "예산을 가장 중요하게 본다."
- 가상 관계자 B: "안전 확인을 받지 않은 자원은 절대로 배정하지 말라."
- 가상 관계자 C: "일부 업무는 반드시 특정 시간에 끝내야 한다."
- 위 내용만으로 결정변수·목적함수를 확정하기 어렵다. 필요한 데이터, 범위, 예외를 추가 확인할 질문을 먼저 정리하라.

이 사례들은 모두 공개 지식으로 자체 구성한 합성 연습 문제다. 대회 문제·조직 내부 규정·평가기준을 재현하지 않는다.
