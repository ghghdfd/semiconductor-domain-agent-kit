# 이해시키기 (Easy Explainer) — Codex 호환판

기반: 사용자 제공 `my_skill.zip/easy-explainer/SKILL.md`. 의미 보존 중심의 설명 구조를 유지한 간결한 Codex 버전이다.

## 목표

기술적 진실과 모든 수치·조건을 유지하면서 비전문가도 따라올 수 있도록 설명한다. 단순한 요약이 아니라 **전문 용어의 정확한 번역**이 목적이다.

## 실행 절차

1. **원문 확보:** 대상 파일·코드·설계 기록이 있으면 직접 읽는다. 없는 사실을 만들지 않는다.
2. **청중과 용도 확인:** 비전공자 성인 기본. 사용자가 더 쉬운 설명/기술 사양 수준을 명시하면 조정한다.
3. **핵심 한 줄:** 가장 중요한 결론부터 설명한다.
4. **전체 흐름:** 입력 → 처리 → 결과 → 검증의 관계를 단계별로 보여준다. 중요한 수치·파일명·예외를 그대로 유지한다.
5. **용어 해설:** 독자가 처음 보는 개념을 생활 언어로 풀되, 전문 개념에 대한 오해를 만들지 않는다.
6. **마무리:** 꼭 기억할 2~3가지, 실제 다음 행동을 제시한다.
7. **정확성 확인:** 원문의 기준 시점, 값·단위·고유명사·조건·반례가 누락되거나 바뀌지 않았는지 검증한다.

## 적용·비적용

- 적용: 의사결정 설명, 코드 동작 설명, 개발자와 비개발자 간 의사소통, 기술 보고서 이해.
- 비적용: 사용자가 정밀 기술사양, 코드 실행, 디버깅, 일반 번역을 명시적으로 요청한 경우.
- 시험 중 AI 사용이 허용된 단계에서 학습에 활용할 수 있으나 **AI 사용이 금지된 서술형 단계에는 사용하지 않는다**.
- 외부 모델·API·별도 MCP는 필요하지 않다.

## 출처
- 사용자가 제공한 기존 스킬의 Codex 호환판.
