# Grill Me — Codex 호환판

기반: 사용자 제공 `my_skill.zip/grill-me/SKILL.md`. Matt Pocock의 공개 grilling 접근법을 사용자가 한국어·일문일답 형태로 재구성한 스킬이다. 여기서는 Codex의 도구 가용성과 시간 제한에 맞춰 변경했다.

## 목적과 경계

- 계획, 설계, 요구사항의 **미확정 의사결정**을 명확히 한다. 이 스킬을 실행하는 동안 구현을 시작하지 않는다.
- **한국어 질문 1개 + 추천 답변 1개**씩 제시한다. 사용자의 답을 기다린 뒤 다음 질문을 만든다.
- 코드·문서에서 확인 가능한 사실은 직접 확인하고 사람만 결정할 문제를 물어본다.
- 원본의 `ask_user_question` 도구는 필수가 아니다. 해당 도구가 없으면 **일반 대화**로 한 질문씩 묻는다.
- 허가되지 않은 외부 웹 검색, API, 외부 모델, MCP·개인 원격서버를 연결하지 않는다.

## 모드
- **quick** (기본, 시간 제한 업무 추천): 미확정 결정 중 중요한 것 1~3개만 순차 질문. 나머지는 '미확인'으로 기록한다.
- **full** (사용자가 명시할 때): 중요도·선행조건 순으로 의사결정 트리를 검토. 사용자가 종료하면 즉시 멈춘다.

## 절차
1. 목표, 성공 기준, 데이터, 제약, 증거, 가정, 미확정 사항을 현재 요청과 접근 가능한 파일에서 추출한다.
2. 자료로 확인 가능한 사실을 먼저 처리한다. 모르는 내부 임계값·정책을 추측하지 않는다.
3. 사람이 승인할 선택을 중요도와 의존 관계대로 정렬한다.
4. 최상위 미확정 항목부터 **질문 하나와 추천 답 하나**를 제시하고 답변을 기다린다.
5. 합의되거나 중단되면 **결정 사항 / 근거 / 범위 밖 / 남은 질문**을 요약한다.

## 경계
- 구현·배포·Git Push를 자동 시작하지 않는다.
- 시험의 AI 사용 금지 단계에서는 절대 사용하지 않는다.
- 시험 문제, 개인 응시 자료, 관계자 대화 내용을 공개 저장소에 기록하지 않는다.
